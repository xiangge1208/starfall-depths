- 日期：2026-09-02 整理（G-1 门禁准备）；配套技术证据见 `m3-gate-integration.md`
- 现行裁定：真人试玩改为**用户自测回报**。发现的问题**不阻塞 m3 tag**——严重度只决定后续修复卡的排期。
- 怎么测：Windows 上启动游戏（Godot 4.7.2 打开本项目直接运行，或用已导出的 `starfall.exe`）。建议整体 30~45 分钟。
- 记录格式（每发现一处问题记一条）：
  ```
  [编号] 现象：一句话说清看到了什么
  种子：HUD 右上角数字（主菜单开局也能看到）  截图/录屏：有就附上
  你的感觉：难受 / 一般 / 无所谓（三选一即可）
  ```
- 严重度参考：**P0** = 崩溃、卡死、无法通关；**P1** = 功能坏了或明显伤手感；**P2** = 观感/打磨类。按你自己的判断填，拿不准就只写现象。

## ① Windows 完整通关一局（3 层，每层底有 Boss 房）——约 20 分钟

开局前：主菜单点「开 始」选一名角色。进局后看一眼 HUD 右上角的**层数/种子/金币**，把种子抄下来（出问题好复现）。

逐层做这些事，做到就勾：

- [ ] **打得动**：小怪几枪/几刀能死（不是明显打不动）；近战挥击能把敌弹打回去
- [ ] **躲得掉**：按翻滚穿过弹幕时有无敌帧，能实际躲开伤害
- [ ] **反应跟手**：按键到画面响应没有可感知的迟钝（机测口径是 ≤1 帧，凭手感即可）
- [ ] **受击有反馈**：被打时红边一闪 + 轻微震屏 + 闷响，能立刻意识到掉血
- [ ] **清房推进**：宝箱/商店/雕像/饮料机/事件房至少各遇一次并能正常使用；下一层门能进
- [ ] **三选一增益**：清层时弹出的三选一能正常选卡并生效
- [ ] **Boss 房**：每层底的 Boss 能正常开战、有阶段变化、能打死（第 3 层 Boss 死后进胜利结算）
- [ ] **死亡也试一次**：故意死一次看死亡结算——能看到本局统计和「致死原因」（死亡回顾）
- [ ] **结算与回主菜单**：胜利/死亡结算数据正常，能回主菜单再开一局，蓝晶/解锁有累计

关注点：全程有没有**卡住不动**（人动不了/怪打不死/门开不了）——这是修复卡最关心的；遇到了**别关游戏**，先抄 HUD 上的种子和层数，再截图。

## ② 试炼局 1 次（当日两因子）——约 5 分钟

- [ ] 主菜单点「试 炼」进试炼面板：能看到**当日 2 个因子**的名称/图标/说明（图标是 8 种小徽章）
- [ ] 开一局试炼局：进局后 HUD 上能看到 2 个因子角标；打一会儿，确认因子效果真的在生效（比如「敌人提速」怪确实更快）
- [ ] 死掉/打完出来：试炼面板的**历史记录**里出现今天的记录
- [ ] 主观：两个因子叠在一起「难受但想再试一把」还是「纯折磨」？一句话即可

## ③ Juice v2 手感清单（打完 ①② 的过程中顺路感受，逐条勾「可以/不行/没注意」）

- [ ] 1. **击杀顿帧**：打死怪的那一下有轻微「顿」感（像掐了一下一拍），比以前更跟手；连杀时顿得更明显
- [ ] 2. **Boss 死亡演出**：Boss 死时先定格一下→白屏一闪→慢动作爆散→掉落延迟喷出；演出期间**连按攻击键能快进跳过**，不按也能自己播完
- [ ] 3. **屏震不头晕**：默认档连续打 10 分钟不头晕恶心；（有空再把设置里屏震拉到 0 和 100 各试一分钟，0 应该完全不动）
- [ ] 4. **连击音高**：1 秒多内连续命中，射击音调会一点点变高；停火/换枪后重新爬升
- [ ] 5. **粒子好看不闹**：打中火花分得出火/冰/毒/电颜色，暴击是金色更大一撮；枪口开火有火光；怪死有碎片；混战里不觉得乱
- [ ] 6. **伤害数字可读**：暴击数字会弹跳放大；中毒/烧灼的小字跳得比主字小；混战里能看清自己打了多少
- [ ] 7. **快死时的红晕**：血量≤2 时屏幕边缘红晕一呼一吸（约 0.8 秒一下），提醒到位但不闹眼睛
- [ ] 8. **受击方向**：被打时角色身旁有一道小弧光指向打你的方向（背后来刀也能知道方向）
- [ ] 9. **翻滚无敌复检**：贴着弹幕翻滚穿越不受伤（老项目点，顺手确认 v2 没弄坏）
- [ ] 10. **字号锐利**：伤害数字和状态小图标放大看不发糊（像素字边缘是脆的）

## ④ 设置面板 + 按键重映射实操——约 5 分钟（主菜单点「设 置」「按 键」）

- [ ] **设置面板 10 行都在**：屏震/伤害数字/色弱形状/自动瞄准/触屏控件/打击停顿/振动/主音量/音乐/音效
- [ ] **开关即点即生效**：关掉「伤害数字」再打几下怪，数字不跳了；打开恢复。音量滑条拖到 0 静音、拉满变响
- [ ] **重启保留**：改 2~3 项设置（比如屏震 0、音量 30）→ 退游戏重进 → 设置还是改过的样子（存档没丢）
- [ ] **改键**：「按 键」里 9 个动作都能点：点「射击」→ 按 新键（比如 F）→ 用新键能开枪、旧键（鼠标左键）失效
- [ ] **改键冲突**：把两个动作改成同一个键 → 应弹提示并**拒绝**，不悄悄覆盖
- [ ] **恢复默认**：点「恢复默认」→ 全部回到出厂键位，立刻生效
- [ ] **改键重启保留**：改一个键 → 重启游戏 → 新键仍然生效

## ⑤ 像素字体走查（中文发糊/缺字/截断快扫，5 分钟）

必看三处（S-C 字体接线后的重点样本）：

- [ ] **战斗 HUD**：武器名/层数/种子/金币/增益小牌的中文 12px 清爽不糊；增益小牌不溢出
- [ ] **结算页**：死亡/胜利大标题（24px）锐利；统计行和致死原因两行内不截断；试炼局的标题带「每日试炼 · 」前缀也不破版
- [ ] **图鉴**：主菜单→图鉴，7 列格子名称完整、解锁条件行数内可读，滚动顺畅

顺手快扫（有问题才记）：主菜单大标题、选角 6 张卡（已知横向排布偏挤——卡**内**文字可读即过，布局问题另有安排）、三选一/灾厄面板、设置/试炼/天赋面板、成就右下角提示、熔铸台。

## ⑥ Android 触屏（有安卓真机才做；无设备 → 本节整节标「跳过」即可）

装包：把 `starfall-release.apk`（versionCode=100，可覆盖装旧包）传到手机安装。

- [ ] **装得上、进得去**：安装成功，图标是石门流星图（非 Godot 默认蓝人形），能进主菜单不闪退
- [ ] **虚拟摇杆**：左手摇杆走位顺滑；右侧推即开火，双摇杆能单手完成一整层
- [ ] **自动瞄准**：不碰瞄准方向时，会自动朝最近敌人开火（设置里关掉「自动瞄准」后失效）
- [ ] **振动**：设置里振动开着时——被打一下有短振（约 30ms），打死 Boss 有一记长振（约 80ms）；关掉开关后两处都不振
- [ ] **试炼面板**：触屏能正常开合、因子卡可读、能开一局试炼
- [ ] **帧率体感**：正常打一局不觉得明显卡顿掉帧（不用仪器，体感即可；若明显卡，记下是第几层什么场景）
