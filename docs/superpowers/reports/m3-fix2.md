## 2. 前任已证事实（本卡复核后）

### 2.1 采信的事实

1. **产品侧根因 A「冻结玩家」**：combat_a1_01 模板把 2×2 石柱阵放在**房心格 (10,6)~(11,7)**（`data/rooms/a1_templates.json`，world x∈[160,192], y∈[512,544]，恰以外框中心 (176,528) 为块心）；a1_05 箱柱列 (11,5..8)、a2_06 晶柱 (10,6)(11,6)、a3_06 石柱 (10,6)(11,7) 同样压住房心。生产 `_push_back`（enter_room 拒绝路径）与 `_place_player_at_start` 的「房心落位」把玩家 CharacterBody2D（r=6）直接放进实体内部，move_and_slide 去重叠相互抵消 → **玩家全程零位移**。
   - 探针实证（修复前捕获 7 例，全部此族）：3205-a2 / 3221-a1 / 3221-a2 / 3223-a3 / 3251-a4 / 3258-a5 / 3268-a4（`m3-fix2-probe/probe-*.json`）。共同签名：密集窗 10s + 触发前环形缓冲 20s 内玩家位置 **unique pp = 1~2 / 80 样本**，注入 dir 非零且持续翻向，活敌（弩兵）血量恒定。我逐 JSON 复核成立。
2. **产品侧根因 B「拾取死物」**：elite 清房 hearts2 奖励经 `_scatter` 自**房心**散布，落点可落进柱/箱实体内部 → 红心无磁吸（`pickup.gd` 仅 coin 有磁吸且磁吸穿墙），实体隔断判定圆 → **任何站位都摸不到**。探针实证：3271-a1（前任，修复态半）：bot 的红心寻路注入原始向量 `dir=(-21.5,0.5)`（= heart_pos−player_pos）顶死箱柱东面，pp 零位移，heart 坐标 (176.5,541.5) 落在箱柱矩形内。
3. **bot 侧残差「风筝弩兵 × 弹不 lead」**：修复态下玩家自由移动（dense unique pp 35~40/40）、auto-aim 锁定且瞄准误差 ≤0.5°，但弩兵以 60px/s 横向风筝、bot 距离带保持 ~150-200px；老伙计弹速 320px/s、飞行 ~0.5s 内敌横移 20-30px，弹**无预判 lead** → 10s 密集窗内弹对敌最近逼进 appr_min = 9.7~14.2px，恒大于命中阈值 **9px（弹 r=3 + 弩兵 r=6）**，cross_hits=0、敌血恒定。敌可被任何攻击抵达（真人走近即点杀）→ 按裁决标准 = **bot 侧**。实证：3217-a4、3221-a2（前任修复态）、**3223-a1（本卡修复态新捕获）**。

### 2.2 修正/推翻的前任断言

1. **前任测试代码从未被验证**：`assert_fail()` 不是 gdUnit4 API，`test_floor_scene.gd` 整套 Parse error 弃载（`Abnormal exit with 105`）。修复为 `fail()` 后全绿——前任修复的正确性证明在本卡才首次成立。
2. **fix 注释把 combat_a1_03 列入「房心实体」模板不精确**：a1_03 房心格 (11,7) 实为 16px 箱间缝，r=6 圆心居中距两侧箱面 8px ≥ 6px，落位**合法**——`find_safe_placement` 对其零漂移原样返回。列名过宽但无害（函数自守）；a1_01/a1_05/a2_06/a3_06 经模板数据核实确为房心受压。
3. **探针 `cross_hits` 指标不作为产品侧命中链缺陷依据**：该指标用「弹本拍位→下拍位」线段最近距离 ≤ 半径和，比引擎的「推进后端点」判定宽（`combat_system.gd:155` 只测端点距离）——3268-a4 的 cross=7 属探针口径假阳性，不采信为「弹命中而血不掉」。本卡所有裁决依赖的是不受此影响的 pp 零位移、血曲线恒定、appr_min > 9px 三项。
4. **前任对 3271 的拾取钳制修复完成后未及复验**——本卡修复态捕获 3271-a3 证实：钳制**已生效**（28 个拾取物全部在实体外、逐坐标验算 ≥6px 间距），bot 仍楔死在柱南面寻心 → 残差归 bot 寻路（§3 seed 3271 行）。

## 6. 给 G-1 的结论（残差是否影响真人通关）

**不影响。** 两族产品侧缺陷在真人路径上的可达面与危害已被本卡消除并以测试钉死：

1. 冻结玩家：真人正常徒步进房不经 `_push_back`（门闸实体拦截 + `_detect_room_enter` 走物理位置）；可达路径仅 start 落位（start_a1 无房心实体）与理论拒绝路径——且两条路径现均经 safe placement，物理上不再可能把玩家放进实体。
2. 拾取死物：所有奖励/掉落落点钳制在实体外 ≥6px，红心 12px 判定圆内必可拾取；金币另有 56px 穿墙磁吸兜底。
3. 修复态残差停滞（~6.5% 局级，上界估计）全部为 bot 能力缺陷：弩兵风筝时弹无 lead + bot 不贴近 + 寻路无绕障。真人对应操作（走近点杀、绕柱拾取）均为基础操作面能力，不构成真人「永不可清」风险。移交数据见 §3 末。
