## 3. 死因结构（归因 → 迭代方向）

1. **miniboss 接触（≈42 局）**：180 HP 持久战（bot DPS 12 → 15s+）期间大体积（radius 7 vs 小怪 5~6）高频接触；决策层观测无半径维度，MELEE_GAP 80px / RANGED_BAND 72~132 按小怪标定→拉开带失效。死因谱：电磁蛛、腐沼巨蟾、石盾武僧、双刀蜥人（dash 300）。
2. **藤蔓巨像（37 局，0 生还）**：P1 藤蔓横扫为全宽移动条带（36 拍横穿+预告），P0 巨掌拍击近身 AoE；bot 的 hazard 观测只收房间静态陷阱，Boss 攻击预告区不可见→站桩吃横扫。
3. **残差 8 局**：初判为 3271 式双红心意图抖动极限环（m4-b3 §3 已归因形态），待卡 C 探针证实后以目标黏滞修复。
