- 关联：m3-fix2 §3「bot 侧量化移交」三可修点 + 欠账清单 #14/#15；Task B-3（`feat(m4-b3): bot capability + save isolation`）
- 复跑构建：**m4-b3 @ ec1956f**（worktree m4-b3；全量 1821 cases 全绿后跑批）

**实现期经三次残差实证迭代收紧（每步探针捕获 → 归因 → 修复 → 单测回归钉）**，迭代证据随本报告归档：

1. **迭代①（归一化缺失）**：首轮批跑 seed 3230 捕获（该批中断重跑，捕获文件未保留；形态已由单测钉死）——寻的向量未归一，47px seek 把 O(1) 斥力/滑移淹没，8 向量化垂直分量低于 0.35 阈值，顶死柱面复发（记录 dir (46.2,−0.2)→探针 snap (46.0,0.0) 与理论合成逐位吻合）。修复 = `seek_with_solids` 内归一；回归钉 `test_seek_with_solids_normalizes_large_magnitude_seek`。
2. **迭代②（滑移对消死区）**：`m4-b3-probe/probe-{3217-a2,3221-a1}.json`——wander_sign 定向滑移在两枚平行箱面上同向叠加（+1.33x）对消寻的（−0.956x），净向量 (0.34,−0.27) 双轴同时落入 8 向死区 → 玩家零输入定死。修复 = 滑移方向对齐意图（帮助绕行）。回归钉 `test_seek_with_solids_no_dead_zone_equilibrium`。
3. **迭代③（错切向互拍）**：`m4-b3-probe-fixchk2/probe-3230-a2.json`——两枚错切向箱面的「对齐滑移」互拍（垂直净剩 0.245 < 0.35）+ 径向西推 → 单轴顶死箱面。修复 = 滑移只取最近面单源（单滑移的切向轴分量结构性 ≥0.7，数学保证见 decisions 注）+ `seek_with_solids` 死区兜底。回归钉 `test_seek_with_solids_nearest_slide_rounds_corner`。

三次迭代的复现与修复均以决策层纯函数单测钉死（`tests/unit/test_balance_bot_decisions.gd` 59 cases），后续回归先红。

## 3. 残留例归因（3271-a1，唯一残留）

- 捕获：`m4-b3-probe-final/probe-3271-a1.json`（t=96.7s，elite 房 3 已清、alive=0，hp 6/8 缺血寻心）。
- 几何：房心 2×2 柱列（x∈[176,192], y∈[496,544]，16×48 竖列 = m3-fix2 记录的同款房心柱模板）西侧 4 枚红心；玩家贴柱东面 (201.5, ~517)，最近红心 W 侧 (165.5,517.5) d=36.1、次近 SW 侧 (169,544) d≈41。
- 形态与原 a3 不同（**软化**）：原 a3 是「Seek 原始向量顶死柱面、pp 10s 零位移」的硬楔死；本次 pp 密集窗内 9 个唯一位置、vel 33.5——玩家保持机动，但在柱面东沿 ~5px 幅度振荡，净推进 ≈0，无法在 180s 签名窗内绕过柱列端点。
- 根因（决策层目标切换抖动）：`_nearest_heart` 逐拍重选，红心 W/SW 的距离曲线在 y≈525 交叉——玩家南下 ~5px 最近心即从 W 翻转为 SW，`seek_with_solids` 的滑移符号（signf(t·intent)）随之北/南翻转，绕柱方向承诺被逐拍撤销 → 极限环。属「初版斥力场（无寻路承诺/无目标黏滞）」的已披露能力边界，非本次三修复的回归：无弹不中、无硬楔死、移动性保留。
- 处置：**接受为初版绕障的已知边界**（任务规格明示「初版斥力场即可，不要求完整寻路」），残留例归因入档；候选硬化方向（目标黏滞/绕行方向承诺）留待 bot 能力后续卡或 B-4 全量复跑数据触发，不在本卡窗口内加机制。
