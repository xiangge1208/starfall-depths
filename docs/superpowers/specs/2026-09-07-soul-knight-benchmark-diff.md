# 元气骑士对标复盘：玩法/流程差异与可借鉴清单（2026-09-07）

- 性质：产品调研，不是实施计划——每条借鉴项落地前仍须按「先做详细设计」惯例出量化 GDD 附录 + 门禁口径
- 对标基准：元气骑士（Soul Knight，凉屋游戏，含近年赛季迭代：角色专属武器/觉醒技能/赛季模式等）；资料源见文内引注

## 2. 结构性差异（流程与体验分叉点）

### 2.1 层内拓扑：线性走廊 vs 节点分叉
元气骑士每层是**线性主路 + 支线房间**，玩家几乎不选路；星陨是 **13 节点分叉图**（Boss=最深叶、商店主路中段、宝箱/事件挂支线）——更接近杀戮尖塔的路线规划。这是星陨的差异化优势（GDD「随机中留选择」支柱的落点），不需要向元气骑士看齐；反过来提示：节点图的价值要靠**支线奖惩对比度**支撑（如挑战房必出紫 + 大量金币 vs 宝箱房风险箱），内容上值得持续加深而非改拓扑。

### 2.2 角色深度：数量 vs 单角色厚度
元气骑士 20+ 角色 × 每角色 2~3 技能（+赛季觉醒技能）；星陨 6 角色 × 1 技能，**技能强化是纸面设计未接线**（GDD §6，M4 economy 报告披露）。星陨的单角色操作面更厚（翻滚无敌帧是元气骑士没有的），但**构筑复玩性的最大缺口在这里**：同一角色局与局之间只有武器/增益变化，技能维度是死的。

### 2.3 空手状态：手刀 vs 无力
元气骑士**永远有手刀**（徒手快速挥击，可反弹弹幕）——近战反弹的对标核心技巧在空手时依然成立，且是「蓝空困境」的保底答案。星陨蓝空时近战武器照常可用（等价设计），但**真·空手（无近战武器）时无任何攻击手段**。手刀是低成本、高契合（签名系统 #1 的延伸）的借鉴点。

### 2.4 复活：一次性复活 vs 无
元气骑士每局可付费/看广告复活一次；星陨 GDD §14.2 **已设计复活图腾（一次性，Boss 房前，150 金）但未实现**——且 `totem_revive` 贴图已在盘（M4.5 u2 披露「挂图=死物」）。这是唯一一条「GDD 已定锚点、资产已备、只差实现」的借鉴项。

### 2.5 武器构筑的正交层：配件
元气骑士有**配件系统**（瞄准镜/扩容弹匣/折叠枪托等，橙配件质变行为），在「稀有度」之上叠了第二层构筑自由度；星陨的武器维度只有稀有度+元素+特性文本。115 把武器的表驱动架构（JSON）天然能承载配件层（新 data 文件 + WeaponRig 应用逻辑），是构筑深度的最大杠杆。

### 2.6 解锁驱动力：材料打造 vs 条件解锁
元气骑士用**蓝图 + 材料掉落 + 打造**解锁武器（收集欲 + 打造期待感）；星陨用图鉴任务条件解锁（计数器达标）。两者都成立，但材料层额外承担了**蓝晶/金币之外的第三货币**角色，给「20h 长线」多一条腿。星陨现版本蓝晶唯一消费端是天赋树（经济报告披露），材料系统可作为未来经济扩展的参考模板而非必须。

### 2.7 元气骑士有、星陨 backlog 明确排除的
花园（材料种植 idle）、宠物/坐骑、无尽回廊、本地双人（架构已预留 §18.4）、云存档、每日种子排行榜——均为 2026-08-28 裁定的 v1 不做项。**重启需要用户明示**；其中若重启，优先序建议：每日种子排行榜（试炼模式已有每日种子地基）> 花园 > 宠物 > 双人 > 坐骑。

## 4. 不建议借鉴的

- **角色数量军备竞赛**：元气骑士 20+ 角色靠的是技能差异化稀释后的广度；星陨 6 角色 × 技能强化（#3）先做厚，数量扩张到 8~10 之前无必要。
- **在线联机**：GDD §18.4 明确二期，本地双人的架构预留已足够表态；联机的回滚/权威服务器成本远超当前团队结构。
- **广告/体力/付费墙结构**：GDD「纯单机，无内购」铁律。
- **赛季 Live-ops**：单机节奏不同，里程碑门禁制已运转良好；可借鉴的是赛季的「主题内容包」组织方式（如 v1.1 做「熔火」主题小扩展）。

## 5. 落地路径建议

1. **先行卡（低成本高契合）**：#1 复活图腾 + #2 手刀——一张「保底体验卡」，与 M4.5 走查方法论同路（挂图死物清算）。
2. **与待裁定合并决策**：#3 技能强化接线上台面时，一并裁定「购买流/选角锁死」（解锁价 2000~8000 蓝晶是现成的 GDD 锚点，economy P1 出带 3.6h 的数据可直接复用）。
3. **v2 内容主杠杆**：#4 配件系统需要先出量化附录（配件池/掉落权重/与稀有度交互），建议与 #9 Boss 专属掉落、#5 升级台合成一张「武器构筑扩展」里程碑（对标 M2 全内容的组织方式）。
4. **纪律提醒**：TTK-R 协议延续——以上全部为「新增内容」项，不触碰现有数值带；孢子手减速（w3 报告待裁定）独立于本清单。
