## 1. 设计规则（全部继承 GDD，新增 3 条）

继承：伤害固定值、暴击唯一随机乘区（基础 5%）；速度带 78~88；HP 5~8 / 盾 3~6 / 蓝 100~160；技能冷却制 CD 8~14s、耗蓝 0~30；**角色差异必须体现在技能改变操作节奏，而非纯数值**（GDD §6）；技能强化 1500 蓝晶/名（GDD §6）。

新增：
- **L1 初始武器带**：新角色初始武器 DPS（damage×rate）落 10~14；越带例外必须附「操作节奏补偿」理由并入档（M4P-BAL 纪律延伸）。
- **L2 签名系统挂钩**：14 名新角色中至少 4 名与三大签名系统（元素共鸣/熔铸/可破坏掩体）有机制级交互，防止新内容游离在差异化核心之外。
- **L3 单人可通关**：所有技能按纯单机设计（无队友依赖；「友军」指召唤物/傀儡/诱饵）。

## 2. 开放策略（2026-09-07 用户裁定：全免费）

**裁定结果（§7 问 1）**：20 名角色**全部免费开放**，无蓝晶购买、无条件解锁门槛——与现役 6 人的产品现状一致。原「混合解锁」方案（8 名购买 28500 + 6 名条件解锁）作废，存档见 git 历史 `43d0b6f`。

对各方的影响：

- **挂账裁定「购买流/选角锁死」就此关闭**：购买流不实施，选角页不做三态角标（锁/价/条件）——只需从横滚 6 人扩容到 20 人。
- **经济影响**：原方案 28.5k 解锁 sink 取消；蓝晶消费端维持「天赋树 10k + 技能强化 30k（1500×20，裁定 3 确认同价）」。强化 30k 是新增长线 sink，节奏验证由 `tools/economy_sim.py` 复跑承担，**降级为门禁内的非阻塞验证项**（不再是实施前置 gate——免费开放没有解锁节奏可破坏）。
- **条件解锁的遗留价值**：原 §2.3 六个条件（近战击杀/掩体击破/试炼通关等）与对应计数器均在产，可转投**成就系统**候选池（后续内容卡参考，本文档不展开）。
