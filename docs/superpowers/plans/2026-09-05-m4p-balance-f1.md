# M4P-BAL 平衡收口计划：bot 过 F1 + TTK 对带（2026-09-05）

- 目标（用户 /goal）：把平衡调整好；切入点 = 「平衡 bot 过不了 F1（AI 能力边界）」
- 对标：GDD §14.3 节奏带（TTK ≤2.0s / Boss 90~150s / 单房 20~40s / 单层 8~12min / 单局 25~35min）+ §8.1 白板 DPS 10~14 + §10 A1 伤害阶梯（弹幕 3 / 接触 4）
- 基线数据：`m4-balance-rerun.md`（100 局：F1 通过 0%、中位局时长 54.5s、A1 杂兵 TTK 5.2s、残差 6%）+ `m4-b3-residual.md`（残差修复方法论）+ `m4-economy.md`（经济 P1）
- 纪律：TTK-R 协议不推翻——真人数据仍是带判定的最终权威；本计划做的是**修仪器**（bot 能力 + 测量口径）与**修客观违规**（实现值违反 GDD 自己的纸面规格），不宣称带已达成

## 2. 量化验收（门禁口径）

**卡 A（游戏数值）纸面验收**：
- 7 把初始武器 DPS 全部落入 10~14（逐把列出调整后实值）
- 苦力虫 aoe_dmg 对齐 A1 阶梯 → 4（纸面 TTK 与失误预算重算入卡）
- GDD 硬规则 6：>±20% 变更回写附录 A（武器表）/附录 B（敌人表）对应行
- 全量测试绿；任何钉旧值的测试期望按证据修复（不许删测试绕过）

**卡 B（仪器）验收**：
- TTK 新口径 = 「首次受击→死亡」（hp 轮询法，零生产侵入；未受击致死如 DoT 单独标记不计入 TTK 分布），旧行为有单测钉
- 自爆虫优先瞄准：最近武装苦力虫 ≤240px 时必为瞄准目标（纯函数 + 单测钉对消/夹击用例）
- 逃逸去对消：武装虫逃离只取最近一只方向 + 切向分量（不跨虫求和），单测钉两虫对夹用例
- 生产零漂移：生产代码（core/）零改动；auto_aim 默认行为单测逐字节钉死

**门禁（合并后 main，bot 100 局全量复跑，协议同 B-4：4 批并行 ×25、独立 save-suffix、18min 帧守门）**：
- 指标（bot 能力口径，披露非玩家胜率）：**F1 Boss 到达率 ≥60%；F1 通过率（进 F2）≥30%；残差 ≤6%；0 崩溃**
- TTK 新口径：**中位 ≤2.0s，P90 ≤5.0s**（带判定仍归真人，此处为仪器可测性验收）
- 观测项（不入门禁，披露口径）：Boss 战时长 vs 90~150s、单房时长 vs 20~40s、F2 段首份数据、gems_curve 供经济模型复校
- 首批未达标：允许一轮探针定向迭代（B-3 方法论：捕获→归因→修复→单测钉），迭代后复跑

## 4. 风险与披露

- 双卡并行下 B 的迭代探针跑在旧数值上：B 的改动是结构性逻辑（瞄准优先级/去对消/口径），不依赖具体数值，合并后门禁批用新数值统一验证——风险可接受
- aoe 8→4 降低 A1 张力：GDD 阶梯优先；自爆虫威胁仍由速度 95>80 + 成群 + 引信节奏保持；真人体感差异待用户自测反馈（裁定㉝通道）
- 武器 DPS +25~50% 全局影响商店估值/熔铸锚点：本次只动 4 把初始白武，商店掉落池不变；经济 P1 仍挂账（门禁批 gems_curve 复校后再议独立卡）
