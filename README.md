# 星陨地牢 Starfall Depths

![Godot](https://img.shields.io/badge/Godot-4.7-478CBF) ![Version](https://img.shields.io/badge/version-1.0.0-blue) ![Tests](https://img.shields.io/badge/tests-1839_passing-brightgreen) ![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Android-orange)

> 像素风俯视角 Roguelike 弹幕射击地牢游戏——双摇杆走位躲弹、海量武器构筑、种子化随机地牢、局外养成。
> 可玩性以《元气骑士》为硬对标，并以 **元素共鸣 / 武器熔铸 / 可破坏掩体** 三大原创签名系统做差异化。

**星舰「晨昏号」坠入大地裂缝**，舰体残骸与地底遗迹层层相叠，渗漏的活性晶体能量「星髓」催生了异变生物。你扮演守夜人，沿坠落井深入三层地窟，回收星核、点亮灯塔。叙事通过 NPC 台词、房间涂鸦与道具描述碎片化呈现，无过场动画、不阻塞玩法。纯单机，无内购。

## 游戏特色

- **手感即正义**——输入到画面响应 ≤ 1 逻辑帧（16.7ms）；命中白闪 + 击退 + 火花，暴击 hitstop，击杀爆散粒子，受击屏震。屏震强度 / 伤害数字 / hitstop 均可在设置中调节（无障碍）。
- **随机中留选择**——种子化地牢每局不同，但构筑由你决定：路线分支、双武器取舍、增益三选一、买与攒。
- **死亡可归因**——伤害为固定值（暴击是唯一随机乘区），敌方弹幕必有 ≥0.35s 预警，死亡回顾界面告诉你死于什么、下次怎么改。
- **十分钟一爽点**——战斗房 20~40s、每层 8~12min、单局 25~35min，节奏点位上必有奖励。
- **局外长线成长**——蓝晶解锁角色与技能强化、天赋树 24 节点点出永久强化、图鉴解锁 49 项武器入库任务、24 项成就；死亡也保留 50% 蓝晶，保底成长感。
- **试炼模式**——5 种挑战因子组合的独立挑战，蓝晶收益 ×1.5。
- **完整的 2.5 小时首周目节奏**——预期 2~3 小时解锁第一名付费角色，约 42% 武器（紫/橙 49 把）需图鉴解锁后进入掉落池，构成约 20 小时长线目标。

## 三大签名系统

### ⚡ 元素共鸣

四元素（**火 / 冰 / 毒 / 电**）命中积累状态值，触发燃烧、冰缓、中毒、麻痹四种独立状态；**同一目标身上两种状态相遇时触发共鸣**：

| 组合 | 共鸣 | 效果 |
|---|---|---|
| 火 + 冰 | **淬爆** | 清除两状态，90px AoE 爆发最后一击 150% 伤害 |
| 火 + 毒 | **燎原** | 生成毒火云 3s，持续伤害并可向周围敌人**传播** |
| 冰 + 电 | **超导** | 目标 4s 内受到的所有伤害 +40% |
| 毒 + 电 | **电解** | 目标及周围至多 3 个敌人硬直 0.8s |

武器本身不带共鸣——**构筑的本质是用增益与武器组合把两种元素带进同一个房间**。

### ⚒ 武器熔铸

每层固定一座熔铸台：投入 2 把武器换 1 把。**15 条固定配方**（多把橙色武器的唯一获取途径）+ 通用升级（同稀有度两把合成 +1 稀有度随机武器，每局限 2 次）。

### 🧱 可破坏掩体

晶柱 / 木箱 / 残骸有 8~20 HP，双方弹幕皆可摧毁，打掉后改变弹道视线——每一场战斗的地形都是动态的。A2 起 Boss 还会使用掩体重建机制。

## 可选角色

| 角色 | 定位 | 被动 | 主动技能 |
|---|---|---|---|
| 骑士·凛（免费） | 新手均衡 | 坚守：护盾破碎瞬间震晕周围敌人 | **狂潮**：8s 副手复制主武器双持齐射，期间免蓝耗 |
| 游侠·苇 | 走位暴击 | 鹰眼：暴击率 +10% | **影袭**：瞬步 140px（无敌），4s 内射击必暴击 |
| 法师·烬 | 元素轰击 | 回响：法杖/激光伤害 +15% | **奥术新星**：冰霜新星 24 伤害 + 冻结 1.2s |
| 刺客·蝉 | 近战反弹 | 掠影：近战击杀返蓝，1s 内翻滚无冷却 | **残影斩**：突进 220px 无敌，击杀则刷新冷却 |
| 工程师·铆 | 召唤阵地 | 备件：开局带便携炮台，每层补给 | **自动炮台**：部署炮台，强化后追加导弹 |
| 守护者·萄 | 生存辅助 | 祝福：每进新层回满护盾并 +5% 全伤害 | **生命潮汐**：回 2 HP + 3s 治疗法阵 |

近战武器全部带 **0.12s 反弹窗口**——窗口内挥砍把敌方弹幕打回敌方阵营，近战挥砍区同时是无敌判定区，这是对标元气骑士的核心技巧。

| 层 | 生态 | 主题机制 | 层 Boss（2 择 1） |
|---|---|---|---|

## 快速开始

1. 安装 [Godot 4.7](https://godotengine.org/download)（标准版即可，无需 .NET）。
2. 用 Godot 打开本仓库根目录的 `project.godot`。
3. 按 F5 运行。

或直接运行已导出的 Windows 成品：`user_export/starfall.exe`（本地构建产物，不入库）。

## 测试与质量保障

M4 门禁基线（v1.0.0 发布口径）：

- **1839 个测试用例全绿**（gdUnit4，90 套件），零孤儿资源
- **9000 随机种子地牢生成校验**（3000 种子 × 3 生态）：全节点可达、门位对齐、Boss 为最深点、商店经济可用
- **存档 v2 往返测试 99/99**，版本化 + migration
- **成就 24/24 接线核验**、经济判定入档
- **性能预算硬指标**：开发机 60fps、活动实体 ≤300、同屏弹幕 ≤500、draw call ≤150、逻辑帧 ≤6ms
- 美术/音频均为程序化生成管线产物（`tools/spritegen` / `sfxgen` / `musicgen`），CI 校验"源参数表 → 产物"一致性

## 技术架构

Godot 4.7 / GDScript，480×270 像素完美渲染（nearest + 整数缩放）。

| 决策 | 选择 | 理由 |
|---|---|---|
| 逻辑帧 | 固定 60Hz accumulator + 渲染插值 | 手感稳定，为种子回放/将来联机留门 |
| 弹幕碰撞 | 自研空间哈希（32px 格） | 500 弹预算内 <1ms，绕开 Area2D 开销 |
| 对象池 | 弹幕/粒子/伤害数字全池化 | 热路径零分配 |
| 数据 | 全内容 JSON + 启动 schema 校验 | 改表即改游戏 |
| 随机 | 每层独立 RNG，种子链派生 | 可分享种子、可回放 |
| 存档 | `user://save.json` 版本化 + migration | 局外进度/设置/图鉴 |

全局单例（autoload）：`game_db`（数据表）、`run_state`（局内状态）、`save_system`、`event_bus`、`audio_mgr`、`scene_router`、`rng_svc`。联机未实现，但固定帧 + 种子化 + 输入即消息的架构为本地双人预留了空间。

## 开发方式

单人 + 子 Agent 编排流程（superpowers 方法论）：任务卡 → TDD 实现 → 规格评审 + 代码评审双 PASS → 合入 main；里程碑末跑集成守卫门禁。约定见路线图 §2；conventional commits，任务号入 message。

Backlog（v1 明确不做，防蔓延）：宠物、花园、无尽回廊、本地双人、云存档、每日种子排行榜。
