# 星陨地牢 Starfall Depths

![Godot](https://img.shields.io/badge/Godot-4.7-478CBF) ![Version](https://img.shields.io/badge/version-1.0.0-blue) ![Tests](https://img.shields.io/badge/tests-1898_passing-brightgreen) ![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Android-orange)

> 像素风俯视角 Roguelike 弹幕射击地牢游戏——双摇杆走位躲弹、海量武器构筑、种子化随机地牢、局外养成。
> 可玩性以《元气骑士》为硬对标，并以 **元素共鸣 / 武器熔铸 / 可破坏掩体** 三大原创签名系统做差异化。

**星舰「晨昏号」坠入大地裂缝**，舰体残骸与地底遗迹层层相叠，渗漏的活性晶体能量「星髓」催生了异变生物。你扮演守夜人，沿坠落井深入三层地窟，回收星核、点亮灯塔。叙事通过 NPC 台词、房间涂鸦与道具描述碎片化呈现，无过场动画、不阻塞玩法。纯单机，无内购。

## 游戏特色

- **手感即正义**——输入到画面响应 ≤ 1 逻辑帧（16.7ms）；命中白闪 + 击退 + 火花，暴击 hitstop，击杀爆散粒子，受击屏震。屏震强度 / 伤害数字 / hitstop 均可在设置中调节（无障碍）。
- **随机中留选择**——种子化地牢每局不同，但构筑由你决定：路线分支、双武器取舍、增益三选一、买与攒。
- **死亡可归因**——伤害为固定值（暴击是唯一随机乘区），敌方弹幕必有 ≥0.35s 预警，死亡回顾界面告诉你死于什么、下次怎么改。
- **十分钟一爽点**——战斗房 20~40s、每层 8~12min、单局 25~35min，节奏点位上必有奖励。
- **局外长线成长**——蓝晶点出 24 节点天赋树永久强化，49 项图鉴任务把紫/橙武器解进掉落池，24 项成就；死亡也保留 50% 蓝晶，保底成长感。
- **试炼模式**——每日种子 + 从 8 条挑战因子中抽 2 条的独立挑战，蓝晶收益 ×1.5。
- **约 42% 武器（紫/橙 49 把）需图鉴解锁后进入掉落池**，构成长线目标。

## 三大签名系统

### ⚡ 元素共鸣

四元素（**火 / 冰 / 毒 / 电**）命中积累状态值，触发燃烧、冰缓、中毒、麻痹四种独立状态；**同一目标身上两种状态相遇时触发共鸣**：

| 组合 | 共鸣 | 效果 |
|---|---|---|
| 火 + 冰 | **淬爆** | 清除两状态，90px AoE 爆发最后一击 150% 伤害 |
| 火 + 毒 | **燎原** | 生成毒火云 3s，100px 内持续伤害并可向周围敌人**传播** |
| 冰 + 电 | **超导** | 目标 4s 内受到的所有伤害 +40%（Boss +20%） |
| 毒 + 电 | **电解** | 目标及周围至多 3 个敌人硬直 0.8s |

武器本身不带共鸣——**构筑的本质是用增益与武器组合把两种元素带进同一个房间**。

### ⚒ 武器熔铸

每层固定一座熔铸台：投入 2 把武器换 1 把。**15 条固定配方**（多把橙色武器的唯一获取途径）+ 通用升级（同稀有度两把合成 +1 稀有度随机武器，每局限 2 次）。

### 🧱 可破坏掩体

晶柱（20 HP）/ 木箱（8 HP，掉金币）/ 灌木（4 HP）可被玩家火力摧毁，打掉后改变弹道视线与通行——每一场战斗的地形都是动态的。宝石蜂后的蜂巢柱在 P1 阶段会周期性重建。

## 可选角色

6 名角色在 v1 中**全部开放可玩**（解锁价格与技能强化为 GDD 纸面设计，购买流程未接线——见[已知偏差](#已知偏差与-v1-边界)）。

| 角色 | 定位 | 被动 | 主动技能 |
|---|---|---|---|
| 骑士·凛 | 新手均衡 | 坚守：护盾破碎瞬间震晕周围敌人 | **狂潮**（CD 14s）：8s 副手复制主武器双持齐射，期间免蓝耗 |
| 游侠·苇 | 走位暴击 | 鹰眼：暴击率 +10% | **影袭**（CD 9s）：瞬步 140px（无敌），4s 内射击必暴击、弹速 +20% |
| 法师·烬 | 元素轰击 | 回响：法杖/激光伤害 +15% | **奥术新星**（CD 10s / 20 蓝）：120px 冰霜新星 24 伤害 + 冻结 1.2s |
| 刺客·蝉 | 近战反弹 | 掠影：近战击杀返 5 蓝，1s 内翻滚无冷却 | **残影斩**（CD 8s）：突进 220px（无敌），4s 内射击必暴击、弹速 +20% |
| 工程师·铆 | 召唤阵地 | 备件：开局带便携炮台，每层补给（与技能共用库存上限 2） | **自动炮台**（CD 12s）：部署炮台，存活 12s、2 次/s |
| 守护者·萄 | 生存辅助 | 祝福：每进新层回满护盾并 +5% 全伤害（最高 4 层） | **生命潮汐**（CD 14s / 30 蓝）：回 2 HP + 3s 治疗法阵 |

近战武器全部带 **0.12s 反弹窗口**（挥击 9 帧中的第 3~9 帧）——窗口内挥砍把敌方弹幕打回敌方阵营，近战挥砍区同时是无敌判定区，这是对标元气骑士的核心技巧。

| 层 | 生态 | 主题机制 | 层 Boss |
|---|---|---|---|
| A1 | 翠绿遗迹 | 教学层：直线弹幕、基础走位；藤蔓减速、滚石碾压 | **藤蔓巨像**（固定） |

## 操作说明

| 动作 | 键鼠 | 手柄 |
|---|---|---|
| 移动 | WASD / 方向键 | 左摇杆 |
| 瞄准 / 开火 | 自动瞄准最近敌人 + 左键开火 | 右摇杆（推即射） |
| 翻滚（全程无敌） | Shift 或 空格 | A |
| 主动技能 | F | RB |
| 切换武器 | Q | LB |
| 交互 | E | X |
| 暂停 | Esc | Start |

翻滚距离 56px / 0.22s、冷却 0.7s、期间全程无敌；受击后 0.8s 无敌帧；护盾 3s 未受击后开始回复（1.2s/点）。所有按键可在设置中重映射。移动端有虚拟摇杆触屏方案。

**自动瞄准**（默认开，设置中可关）：全向索敌，朝向自动锁定最近的敌人，不必用鼠标去追。
键鼠端仍需按左键开火；触屏端锁定即自动开火（免按键）。关闭后键鼠回到鼠标指向瞄准。

## 快速开始

1. 安装 [Godot 4.7](https://godotengine.org/download)（标准版即可，无需 .NET）。

## 测试与质量保障

当前 main 基线（本地复跑口径）：

- **1898 个测试用例全绿**（gdUnit4，103 套件），零孤儿对象
- **9000 随机种子地牢生成校验**（3000 种子 × 3 生态）：全节点可达、门位对齐、Boss 为最深点、商店经济可用
- **存档 v2 往返测试 99/99**，版本化 + migration
- **成就 24/24 接线核验**、经济判定入档
- **性能预算硬指标**（`tests/scenes/perf_probe.tscn` 实测）：逻辑帧 ≤6ms（实测 0.02~0.03）、活动实体 ≤300（实测 62~65）、同屏弹幕 ≤500、draw call ≤150（窗口化实测 F2 峰 149）
- **数据全表可达性绊线**：`enemies.json` 每一行都必须能在产品内出现（波次池 ∪ 召唤链闭包 ∪ Boss 召唤常量），新增死数据即红
- 美术/音频均为程序化生成管线产物（`tools/spritegen_m3.py`、`gen_placeholder_*.py`），`tools/art_qa_check.py` 校验对比度/连通域/空帧三项（当前 565 检查项、47 条基线豁免）

> 无 CI：以上校验目前均为**本地手工执行**，门禁证据落 `docs/superpowers/reports/`。

## 技术架构

Godot 4.7 / GDScript，480×270 像素完美渲染（nearest + 整数缩放）。

| 决策 | 选择 | 理由 |
|---|---|---|
| 逻辑帧 | Godot 原生固定 60Hz `_physics_process` | 手感稳定，为种子回放/将来联机留门（未开渲染插值） |
| 弹幕碰撞 | 自研空间哈希（32px 格） | 500 弹预算内 <1ms，绕开 Area2D 开销 |
| 对象池 | 弹幕（预分配 300 / 上限 500）、粒子（启动建满）池化 | 热路径零分配；伤害数字为短命 Label，未池化 |
| 数据 | 全内容 JSON + 启动 schema 校验（fail-closed） | 改表即改游戏 |
| 随机 | 每层独立 RNG，种子链盐流派生 | 可分享种子、可回放 |
| 存档 | `user://save.json` 版本化（v2）+ migration | 局外进度/设置/图鉴 |

全局单例（autoload）：`GameDB`（数据表）、`RunState`（局内状态）、`SaveSystem`、`EventBus`、`AudioMgr`、`SceneRouter`、`RngSvc`、`Fx`、`Telemetry`、`DeathRecorder`、`CodexSystem`、`AchievementSystem`。联机未实现，但固定帧 + 种子化 + 输入即消息的架构为本地双人预留了空间。

## 已知偏差与 v1 边界

诚实披露——以下为 GDD 纸面设计与产品实现的差异，均在档有据：

- **角色解锁 / 技能强化未接线**：GDD §6 定的解锁价（2000~8000 蓝晶）与强化价（1500/名）在数据表中无字段，`SaveSystem.unlock_hero` 无扣费、选角面板无门槛——产品内 6 名角色全部开放，选角页的锁标仅为视觉。天赋树是当前唯一的蓝晶消费端。详见 `docs/superpowers/reports/m4-economy.md` §2。
- **经济节奏 P1 出带**：「2~3 小时解锁第一名付费角色」的节奏判定基于纸面锚点，目标档实测 3.6h（区间 2.5~18.4h），且购买行为本身在产品内不可发生。
- **残影斩的「击杀刷新冷却」未实现**：`core/player/skills/shadowstep_assassin.gd` 头注明确披露不在实现范围；掠影被动（击杀返蓝 + 翻滚免 CD）已接线。
- **A1 杂兵池仅 4 行**：附录 B.2 为 A1 设计的 12 个特有种，因 F1 池被 M1 门禁校准与平衡基线对照冻结，实际落位在 F2 池（见 `floor_scene.gd` FLOOR_TRASH 注）。是否搬回 F1 属独立平衡决策。
- **平衡 bot 无法过 F1**：bot 100 局 F1 通过率 0%，属 AI 能力结构性边界而非难度判定；单层/单局时长带以真人自测为权威。
- **Android 真机未验证**：无设备，60fps 与触屏全流程为诚实 SKIP。
- **无 CI**：所有门禁校验为本地手工执行。

Backlog（v1 明确不做，防蔓延）：宠物、花园、无尽回廊、本地双人、云存档、每日种子排行榜。
